# 60-second demo video script

Record your screen at 1080p with your voice over it. Keep the browser zoom at about 110% so text is readable.

| Time | On screen | Say (voice-over) |
|---|---|---|
| 0:00 - 0:08 | Home page hero, "Powered by BharatCode" badge visible | "AI agents fail in confusing ways, and finding out why takes ages. This is Agent Autopsy, built on the BharatCode API." |
| 0:08 - 0:16 | Scroll to the debugger, click **Whitespace in tool argument** | "I paste a failed run, or load a realistic example. Here an order lookup returns 404, even though the order exists." |
| 0:16 - 0:24 | Show the filled form, press **Analyze failure**, loading state | "One click sends it to a secure backend that calls a BharatCode model. The API key never touches the browser." |
| 0:24 - 0:38 | Diagnosis appears: title, failure type, confidence, root cause, problematic step | "In seconds I get a structured diagnosis: the failure type, the root cause, and the exact field that failed first: `order_id` has stray spaces." |
| 0:38 - 0:48 | Click **Before / After** tab, then **Copy** on the corrected tool call | "I can compare the original and the fixed prompt and tool call, and copy the corrected call straight into my code." |
| 0:48 - 0:56 | Click **Save case**, scroll to Saved cases, mark as Fixed, click **Download .md** | "Cases are saved locally with an Open or Fixed status, and I can export the diagnosis as Markdown for a pull request." |
| 0:56 - 1:00 | Footer / hero with the GitHub link | "Agent Autopsy. Find why your agent failed, and fix it. Open source, powered by BharatCode." |

## Recording tips

- Load the example and fill the form **before** recording so there is no typing delay.
- If the API is slow, cut the waiting time in the edit.
- Do one test run first and make sure no real secrets are visible on screen.
- Upload to YouTube (unlisted) or Loom and add the link to the README and your submission.
