How it works

Three steps from "why did it do that?" to a verified fix.

1

Paste the failed run

Fill the guided form: objective, system prompt, model response, tool call, tool output and the error. Or load an example.

2

Get a structured autopsy

A BharatCode model finds the earliest likely failure, classifies it and explains the root cause with a confidence level.

3

Copy the fix

Copy the improved prompt or corrected tool call, compare before and after, save the case and download a Markdown report.

    FAQ
    
        
    
        
    
          Is my BharatCode API key exposed in the browser?
          
    No. The browser only talks to a small serverless backend. The key is stored as an environment variable on the backend and is never sent to the page.
    
        
    
        
    
          Is my data stored anywhere?
          
    The backend does not store requests. Saved cases are kept only in your own browser's localStorage and can be deleted at any time. Please do not paste passwords, real API keys or personal data.
    
        
    
        
    
          How accurate is the diagnosis?
          
    It is a model-generated analysis, so treat it as a strong first hypothesis. The confidence field tells you how much evidence the model found. Always re-run the agent with the fix to verify.
    
        
    
        
    
          What should I paste for the best results?
          
    The exact system prompt with tool descriptions, the raw tool call as the agent produced it, the raw tool output and the real error text. Exact text beats summaries.
    
        
    
        
    
          Which model does it use?
          
    Agent Autopsy calls the BharatCode model API using an OpenAI-compatible chat completions request. The model name is configurable on the backend.
